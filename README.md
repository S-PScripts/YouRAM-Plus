> ⚠️ This can only decrease memory for apps installed with apple developer accounts and not with public enterprise certificates.

## How to use
1. [Download](https://github.com/NovaDev404/iRAM-Plus/releases/latest/download/iRAM-Plus.ipa) the latest IPA
2. Sideload this app
3. Sign in with your account that you used to sign the app you want to "Decrease Memory" for
4. Tap the app that you want to "Decrease Memory"
5. Tap "Decrease Memory"
6. Reinstall the app from SideStore/AltStore
7. Check if you have "Decrease Memory"
